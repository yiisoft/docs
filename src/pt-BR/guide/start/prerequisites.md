# O que você precisa saber?

A curva de aprendizado do Yii não é tão íngreme quanto a de outros
frameworks PHP, mas ainda assim há algumas coisas que você deve aprender
antes de começar com o Yii.

## PHP

O Yii é um framework PHP, então [leia e entenda a referência da
linguagem](https://www.php.net/manual/pt_BR/langref.php).

## Programação orientada a objetos

Você precisa de uma noção básica de programação orientada a objetos. Se
ainda não conhece, veja um dos muitos tutoriais disponíveis, como [o do
tuts+](https://code.tutsplus.com/tutorials/object-oriented-php-for-beginners--net-12762).

Ao desenvolver com o Yii, você escreve código orientado a objetos, então
conheça bem o [suporte do PHP a
POO](https://www.php.net/manual/pt_BR/language.oop5.php).

Quanto mais complexa for a sua aplicação, mais conceitos avançados de POO
você vai precisar aprender para lidar bem com essa complexidade.

## Linha de comando e Composer

O Yii usa amplamente o gerenciador de pacotes que é o padrão de fato no PHP,
o [Composer](https://getcomposer.org), então leia e entenda o [guia
dele](https://getcomposer.org/doc/01-basic-usage.md). Se você não tem
costume de usar a linha de comando, é hora de começar. Depois de aprender o
básico, você não vai querer trabalhar sem ela.

## HTTP

Como o Yii é um framework web e a web usa principalmente HTTP, é uma boa
ideia [aprender mais sobre
ele](https://developer.mozilla.org/pt-BR/docs/Web/HTTP).

## Docker

O template de aplicação padrão usa Docker, então recomendamos que você [leia
e entenda os conceitos](https://docs.docker.com/get-started/).

Também vale a pena conhecer os princípios do [twelve-factor
app](https://12factor.net/pt_br/).
