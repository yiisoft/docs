# Aplicações de demonstração

Existem várias aplicações de demonstração que mostram diferentes abordagens
de arquitetura e recursos do framework.

**[Demo Blog](https://github.com/yiisoft/demo-blog) — Arquitetura DDD em camadas**

Uma aplicação de blog que demonstra uma arquitetura em camadas seguindo os
princípios do Domain-Driven Design (DDD).  Esta demo é um bom ponto de
partida se você quer aprender a estruturar uma aplicação Yii3 com uma
separação clara de responsabilidades entre as camadas de domínio, aplicação
e infraestrutura.

**[Demo Diary](https://github.com/yiisoft/demo-diary) — Arquitetura de vertical slices**

Uma aplicação de diário construída com o padrão de arquitetura de vertical
slices.  Nessa abordagem, cada funcionalidade é implementada de ponta a
ponta em vez de ser dividida em camadas horizontais, o que facilita
adicionar ou modificar funcionalidades de forma independente.

**[Demo Summarizer](https://github.com/yiisoft/demo-summarizer) — Resumidor de documentos com modelo de linguagem (LLM)**

Uma demo executável do Yii3 para enviar documentos, extrair Markdown
legível, resumir o conteúdo e acompanhar o progresso do processamento.
