# Seguindo em frente

Se você leu todo o capítulo "Primeiros passos", já criou uma aplicação Yii
completa.  No caminho, aprendeu a implementar alguns recursos comuns, como
receber dados dos usuários por um formulário HTML, buscar dados em um banco
de dados e exibir dados de forma paginada. Também aprendeu a usar o
[Gii](gii.md) para gerar código automaticamente. Usar o Gii para gerar
código transforma boa parte do desenvolvimento web em algo tão simples
quanto preencher alguns formulários.
