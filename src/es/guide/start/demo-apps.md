# Aplicaciones de demostración

Hay varias aplicaciones de demostración que muestran distintos enfoques
arquitectónicos y capacidades del framework.

**[Demo Blog](https://github.com/yiisoft/demo-blog) — Arquitectura DDD por capas**

Una aplicación de blog que muestra una arquitectura por capas basada en los
principios del diseño guiado por el dominio (DDD, Domain-Driven
Design). Esta demo es un buen punto de partida si quieres aprender a
estructurar una aplicación Yii3 con una separación clara de
responsabilidades entre las capas de dominio, aplicación e infraestructura.

**[Demo Diary](https://github.com/yiisoft/demo-diary) — Arquitectura de porciones verticales**

Una aplicación de diario creada con el patrón de arquitectura de porciones
verticales (vertical slices). En este enfoque, cada funcionalidad se
implementa de extremo a extremo en lugar de repartirse entre capas
horizontales, lo que facilita añadir o modificar funcionalidades de forma
independiente.

**[Demo Summarizer](https://github.com/yiisoft/demo-summarizer) — Resumidor de documentos con un modelo de lenguaje de gran tamaño (LLM)**

Una demo de Yii3 lista para ejecutar que permite subir documentos, extraer
de ellos Markdown legible, resumir su contenido y seguir el progreso del
procesamiento.
