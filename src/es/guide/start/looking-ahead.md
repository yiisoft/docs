# Próximos pasos

Si has leído todo el capítulo "Primeros pasos", ya has creado una aplicación
Yii completa. Por el camino has aprendido a implementar algunas
funcionalidades que se necesitan con frecuencia, como obtener datos de los
usuarios mediante un formulario HTML, obtener datos de una base de datos y
mostrarlos paginados. También has aprendido a usar [Gii](gii.md) para
generar código automáticamente. Usar Gii para generar código convierte buena
parte de tu proceso de desarrollo web en una tarea tan sencilla como
rellenar unos cuantos formularios.
